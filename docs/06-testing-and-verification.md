# Testing & Verification Guide

This document details all test procedures, expected outcomes, and diagnostic steps for verifying the Spanner Omni GraphRAG Pickleball Coach application.

---

## 1. Automated Test Suite

The automated test suite in [`test_ai_service.py`](file:///D:/code_vipasana/pickleball/test_ai_service.py) uses Python's standard `unittest` library and mocks network calls to avoid consuming API credits.

### Running Automated Tests

```powershell
$env:PYTHONUTF8="1"
.\.venv\Scripts\python.exe -m unittest test_ai_service.py
```

### Verified Test Cases (20/20 Passed)

- Provider selection for `ollama` and `gemini`.
- Case-insensitivity validation for provider strings.
- Unsupported provider rejection (`ValueError`).
- Missing Gemini key validation when `LLM_PROVIDER=gemini`.
- Verification that Ollama mode does not initialize Gemini.
- Ollama generation success, token tracking, and thinking tag removal.
- Ollama connection error, timeout, and 404 missing model handling without Gemini fallback.
- Ollama health checks against `/api/tags`.
- Gemini generation success and failure isolation.
- Security check ensuring API keys never appear in application logs.
- API status, courts, bookings, and matches endpoint responses.

## 2. Live Integration Checks

### Step 1: Spanner Omni Connectivity

```powershell
docker exec spanner-omni /google/spanner/bin/spanner databases list
```

Expected output:
```text
NAME            STATE    VERSION_RETENTION_PERIOD    EARLIEST_VERSION_TIME          ENABLE_DROP_PROTECTION  
spanner-info    READY    1h                          ...                            false                   
pickleball-db   READY    1h                          ...                            false                   
```

### Step 2: Ollama Endpoint & Model Verification

```powershell
Invoke-RestMethod -Uri "http://localhost:8080/api/tags" -Method Get
```

Expected output contains `gemma4:e2b`.

### Step 3: Application Status Endpoint

Start the Flask application:

```powershell
$env:PYTHONUTF8="1"
python app.py
```

Query the status endpoint:

```powershell
Invoke-RestMethod -Uri "http://localhost:5000/api/status" -Method Get
```

Expected response fields:
- `spanner_connected: true`
- `spanner_error: null`
- `llm_provider: "ollama"`
- `model: "gemma4:e2b"`
- `service_reachable: true`
- `model_available: true`

### Step 4: Live AI Concierge Chat

```powershell
$body = @{ prompt = "What are the rules of the Kitchen NVZ?" } | ConvertTo-Json
Invoke-RestMethod -Uri "http://localhost:5000/api/ai/chat" -Method Post -Body $body -ContentType "application/json"
```

Expected response contains tactical advice generated by the active provider with `spanner_synced: true`.

### Step 5: Rally End & Spanner Session Persistence

```powershell
$body = @{
    winner = "player"
    fault_type = "Out of Bounds"
    rally_length = 5
    shot_sequence = @(
        @{ hitter = "player"; shot_type = "Third Shot Drop"; speed_mph = 28.0; spin_type = "Topspin" }
        @{ hitter = "bot"; shot_type = "Kitchen Volley"; speed_mph = 35.0; spin_type = "Flat" }
    )
    user_score = 11
    bot_score = 8
    bot_difficulty = "5.0"
} | ConvertTo-Json
Invoke-RestMethod -Uri "http://localhost:5000/api/rally-end" -Method Post -Body $body -ContentType "application/json"
```

Verify that the match session appears in Spanner:

```powershell
Invoke-RestMethod -Uri "http://localhost:5000/api/performance" -Method Get
```
